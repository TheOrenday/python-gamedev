# Python Gamedev

Mis ejercicios de Python mientras aprendo desarrollo de videojuegos e IA.

## Archivos
- `adivina_numero.py`: juego de adivinar un número con 7 intentos.
- `gamedev.py`: menú de combate, mochila y funciones.
- `rpg_combat.py`: combate por turnos con diccionarios, funciones, azar y críticos.

## Cómo correrlo
1. Instala Python 3.
2. En la terminal: `python nombre_del_archivo.py`

## Lo que practico
Variables, condicionales, bucles, listas, diccionarios y funciones.
